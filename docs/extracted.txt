1. Initial Migration & Delta Synchronization
5,000 products is a lightweight dataset (~5–10 MB of JSON data without raw images). Standard web API polling for all 5,000 items on every edit will
cause lag.
Migration Strategy (App First Launch)
Bulk Export/Import:  The local backend generates a compressed JSON/SQLite bundle during initialization.
Local Storage:  Store data in SQLite  or WatermelonDB  (React Native/Flutter) directly on the mobile device for instant search (<10ms UI
latency).
Delta Updates (Price & Quantity Changes)
To avoid re-downloading all 5,000 items:
1. Every product row in the backend database has a updated_at  timestamp and an incremental version  sequence.
2. The mobile app tracks its last sync timestamp ( last_synced_at ).
3. Sync Request:  Mobile calls GET /api/products/sync?since=2026-09-07T12:00:00Z .
4. Backend Response:  Returns only the modified or soft-deleted records since that timestamp.
Operation Strategy Payload Size (5,000 products)
Init Migration Gzipped JSON / SQLite File Dump ~2 – 4 MB
Delta Update (10 price edits) Differential Sync API (/sync?since=... )< 5 KB

3. How the Mobile App Manages Sync Logic
1. First Boot (Initial Migration):
Mobile app makes a request with since_version=0 .
Server returns all active items (5,000 items ~2.5 MB compressed).
Mobile performs a bulk transaction inserting all items into its local SQLite / W atermelonDB  database and saves latest_version  (e.g.,
1000 ) locally .
2. Subsequent Syncs (Delta Increments):
App opens and calls /api/v1/sync/pull?since_version=1000 .
Server returns only 3 modified products.
Mobile upserts ( INSERT OR REPLACE ) those 3 items and purges items in deleted_ids .
Mobile updates stored version pointer from 1000  to 1003 .

    // Separate active updates from soft-deletions for easier client parsing
    const updatedProducts = products.filter((p) => !p.is_deleted);

    return reply.status(200).send({

          deleted_ids: categories.filter((c) => c.is_deleted).map((c) => c.id)
        },
        products: {
          updated: updatedProducts,
          deleted_ids: deletedProductIds

def generate_image_embedding(image: Image.Image) -> List[float]:
    """Converts a PIL image into a normalized 512-dimensional CLIP embedding."""
    inputs = processor(images=image, return_tensors="pt").to(device)
    with torch.no_grad():
        image_features = model.get_image_features(**inputs)
        # L2 Normalize the vector so cosine similarity equals inner product
        image_features = image_features / image_features.norm(dim=-1, keepdim=True)
    
    return image_features.cpu().numpy()[0].tolist()

If you are testing via flutter run -d chrome  or the shop counter uses a cheap USB handheld barcode reader :
A USB barcode scanner acts as a keyboard emulator . When it scans a barcode, it types out the digits rapidly and fires an ENTER  key.
You can handle this cleanly in Flutter without a camera using a KeyboardListener :
import 'package:flutter/material.dart';
import 'package:flutter/services.dart';
class HardwareBarcodeListener extends StatefulWidget {
  final Widget child;
  final Function(String barcode) onBarcodeScanned;
  const HardwareBarcodeListener({
    super.key,
    required this.child,
    required this.onBarcodeScanned,
  });
  @override
  State<HardwareBarcodeListener> createState() => _HardwareBarcodeListenerState();
}
class _HardwareBarcodeListenerState extends State<HardwareBarcodeListener> {
  final StringBuffer _buffer = StringBuffer();
  DateTime? _lastKeyTime;
  void _handleKeyEvent(KeyEvent event) {
    if (event is KeyDownEvent) {
      final now = DateTime.now();
      // Hardware barcode scanners type characters in < 20ms intervals
      if (_lastKeyTime != null && now.difference(_lastKeyTime!).inMilliseconds > 100) {
        _buffer.clear(); // Reset if typed manually by human
      }
      _lastKeyTime = now;
      if (event.logicalKey == LogicalKeyboardKey.enter) {
        if (_buffer.isNotEmpty) {
          widget.onBarcodeScanned(_buffer.toString().trim());
          _buffer.clear();
        }
      } else if (event.character != null) {
        _buffer.write(event.character);
      }
    }
  }
  @override
  Widget build(BuildContext context) {
    return KeyboardListener(
      focusNode: FocusNode()..requestFocus(),
      onKeyEvent: _handleKeyEvent,
      child: widget.child,
    );
  }
}
